# fn-knock 2.1.11

- 企业基础设施集成，新增 LDAP / Active Directory 外部登录
- 新增子域流量深度抓包，位于子域管理->更多->深度监控，可查看 HTTP、WebSocket上游与用户数据包明细，并支持导出数据包
- 事件中心新增核心服务状态、资源占用和运行事件，并提供诊断日志及导出
- DDNS 网卡取址可选择使用内网地址
- 飞牛FPK，系统设置->模式->操作，新增“额外放行的端口”功能，支持继续放行防火墙端口
- 修复子域映射重命名后登录策略、可见性及凭证注入等配置可能丢失或被其他别名误继承的问题
- 修复阿里云 ESA、腾讯云 EdgeOne 模式下登录、回调和邀请链接错误携带源站端口的问题
- 管理面板的密码保护与重置指引现在会根据 Docker、OpenWrt、Linux、Windows 等实际部署方式正确显示
- 新增 macOS 13+ CLI 发行版，分别支持 Intel 和 Apple Silicon，通过 launchd 与 `knock` 管理；发行包未使用 Apple Developer ID 签名
