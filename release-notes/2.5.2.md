# fn-knock 2.5.2

- 管理后台桌面侧栏支持折叠，并保存折叠状态，刷新页面后仍可沿用设置。
- 网关导航新增「智能判断局域网环境」选项，可根据访客来源自动选择局域网直连地址或公网访问地址；该选项默认关闭。
- 修复仅获授权访问单个服务时，因登录入口与服务域名的 Cookie 作用域不同而无法正常进入服务的问题，并完善登录跳转及旧 Cookie 清理。
- 登录表单支持浏览器和密码管理器自动填充账号、密码，改善密码登录与 LDAP 登录体验。
- 移除旧版 Redis 自动迁移逻辑，避免历史 Redis 数据覆盖现有 SQLite 配置与数据。
- 新增 Moo 应用源支持，稳定版发布后自动更新完整版 FPK 的版本、下载地址、校验信息和更新日志，方便通过 Moo 获取与更新应用。
