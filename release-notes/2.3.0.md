# fn-knock 2.3.0

- 新增外部证书接收入口，支持 Certd 等工具在签发或续期后自动将证书推送到 fn-knock。
- 完善 Swagger 接口文档的多语言说明。
- 协议映射新增服务识别与严格协议校验，并支持按来源配置免登录规则。
- DDNS 修复 DNSPod 中目标记录不存在时无法自动创建的问题。
- fnOS FPK 管理端新增控制台应用栏（收藏夹），可在系统设置->功能中配置显示的应用入口。
- 加固系统升级期间的 SQLite 数据保护与服务切换流程。
- DDNS 更新间隔最低可设置为 2 分钟。
- 加固 WAF 事件持久化流程，确保写入失败后可以安全重试。
- 会话和 SSH 安全设置新增“月”时长单位。
- 优化Go网关吞吐性能
- 优化认证登录卡片样式。
