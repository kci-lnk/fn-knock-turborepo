# fn-knock 2.4.11

- 新增 HTTP/3 支持，位于系统设置->网关
- 系统设置->维护，自动备份支持邮件发送备份的能力
- 系统设置->日志，支持更换请求日志保存路径
- 支持为 Host 路径规则强制启用登录认证
- 新增 OpenWrt LuCI 网关防火墙手动操作入口
- 请求日志新增每日与总容量上限，默认每日 256 MiB、总计 1024 MiB，可在系统设置中修改并即时生效；超限自动清理最旧分片，继续保留最新请求。
- 旧日志在启动及调低额度时自动清理；查询、分页及统计支持同一天多个日志分片，并显示当前占用、容量丢弃计数与存储异常。已清理记录无法恢复，统计仅覆盖保留的日志。
