# fn-knock 2.5.5

> [!IMPORTANT]
> 本次为重要安全更新，建议所有用户尽快升级。

- 升级 Rust 后端、Go 网关及前端构建链中的多项依赖，修复相关依赖中的已知安全问题，涉及 TLS、HTTP、WAF、压缩包处理等组件。
- 加强发布安全检查：审计依赖、核验各平台 Go 网关二进制与源码的一致性，并扫描最终容器镜像中的系统软件包；发现不符合安全门禁要求的问题时阻止正式发布。
- 补充证书信任校验、压缩包路径穿越与符号链接处理、WAF 等安全回归测试，并完善 SSH 使用 RSA 密钥时的风险提示。
- 修复高级认证条件同步到网关前的规范化处理，使认证规则能够按预期生效。
- 修复 fnOS 证书同步中过期事务的清理与恢复处理，保护仍在使用的证书引用，避免误清理。
- 新增带保护检查的 fnOS 证书同步诊断与过期事务清理工具，便于排查和处理历史同步问题。
