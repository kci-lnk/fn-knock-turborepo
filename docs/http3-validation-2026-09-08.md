## 后续审计与修复

本轮审计检查了 Go 入口、监听与配置事务、Rust 同步及控制 RPC，修复集中在 Go 运行时：

- HTTP/3 成功响应原先固定返回 `Alt-Svc: clear`，会撤销客户端发现记录。现在按当前域名、端口与运行状态生成广播，同时覆盖上游广播。
- Alt-Svc 改为在响应提交时计算，避免长请求开始后关闭 HTTP/3，响应仍广播已停止的入口。
- 证书、域名协议刷新与配置的应用、持久化、回滚共用监听事务锁；启动应用同样串行化，避免刷新读取旧配置并覆盖刚应用的监听范围或开关。状态读取也等待事务完成，保持配置与运行状态一致。
- 异常停止的 UDP listener 不再因地址相同而跳过重建；重新保存配置能够恢复服务。
- 退出会取消正在进行的配置排空，避免先等待一轮 15 秒排空，再使用退出预算；取消后禁止该刷新重新打开监听。
- IPv6 绑定仅对地址族不支持、地址不可用这两类错误降级。权限等其他错误会明确返回，避免误报双栈正常。
- 响应包装器仅在 Hijack 成功时标记已接管响应；失败后的普通错误响应仍正常提交。101 被视为最终响应。

新增回归覆盖响应提交前状态变化、Hijack 失败回退、真实 UDP listener 故障后重试、配置提交与刷新/状态读取并发，以及真实 QUIC 长连接排空时退出。
本轮修复后重新通过：Go 全量 `go test ./...`；`cmd/server`、`pkg/proxy`、`pkg/admin`、`pkg/stream` 的 race 检查；Linux amd64/arm64/armv7、Windows amd64、macOS amd64/arm64 的 Go 交叉编译（`CGO_ENABLED=0`、`GOFLAGS=-mod=readonly`）；业务代码 diff 空白检查。完整暂存检查另发现 quic-go 原始源码中的空白告警，为保持与上游一致而保留。
前面的 Rust/前端结果来自实施阶段，本轮没有修改这些组件。

## 本机传输基准

以下为本轮审计修复前的实施阶段基准，修复后未重新测量性能。
Apple M5，Darwin arm64，Go 1.26.7，非 race 构建。完成编译和回归后单独、依次测量两种协议。
两个协议经过同一 Go Handler 与 HTTP/1.1 回源，返回相同的 64 KiB 数据；单客户端复用连接、顺序请求。
每种协议运行三次 `-test.benchtime=2s`；下表延迟、吞吐及分配量取三次结果中位数。
这是回环网络的开发基准，不代表真实公网或低配 ARM。

| 指标 | HTTP/2 | HTTP/3 |
|---|---:|---:|
| 每请求时间 | 0.153 ms | 0.389 ms |
| 吞吐 | 429.23 MB/s | 168.68 MB/s |
| 每请求分配字节 | 23,597 B | 57,200 B |
| 每请求分配次数 | 247 | 1,034 |
| 测量结束时整个测试进程 goroutine 数 | 23 | 31–33 |
| 整个测试进程峰值 RSS | 62.59 MiB | 64.09 MiB |
| 整个测试进程 user / system CPU 时间 | 13.28 / 15.14 s | 11.10 / 15.67 s |
| 整个测试进程墙钟时间 | 14.25 s | 8.65 s |

RSS、CPU、goroutine 均包含测试客户端、上游、网关及测试框架；CPU/墙钟还包含校准、建连和清理。
两组自适应迭代次数不同，不能用 CPU 总秒数直接比较单请求 CPU 成本。
结果只证明该本机顺序请求场景中 HTTP/3 吞吐较低、分配较多；没有得到性能提升的证据。

可从 Go 仓库复现：

```sh
go test ./cmd/server -run '^$' -bench BenchmarkGatewayHTTP2HTTP3 -benchtime=2s -count=3
```

## 依赖与尚需实际环境验证的部分

quic-go v0.62.0 上游总是声明 Extended CONNECT。Go 仓库保留该版本完整源码和 MIT 许可证，
只修改 `http3/server.go` 增加 `DisableExtendedConnect`，网关显式开启该禁用选项。
已逐文件核对：除这个源文件及新增补丁说明外，vendored 内容与下载的 v0.62.0 一致。
升级时需追踪上游安全更新，并保留 SETTINGS 线上的回归测试。

以下尚未验证，不属于上述通过结果：

- 浏览器在真实受信任证书、Alt-Svc 缓存和 UDP 被阻断环境下的协议选择；现有 WebSocket 测试为真实 TCP WebSocket 客户端，并非浏览器。
- 公网 NAT、路由器、防火墙及 IPv6 的端到端可达性。
- 受控高延迟/丢包网络，以及低配 ARM 实机的延迟、CPU 和内存。
- 跨 IP 迁移的真实网络切换；实现包含每请求对端检查及连接周期检查，但未做真实链路切换实验。
- Rust/NAS/桌面完整安装包的全平台运行。上述六平台结果仅指 Go 网关编译。

发布前应在目标设备完成这些检查。关闭开关可撤销本机 HTTP/3 服务并保留 TCP 入口。
