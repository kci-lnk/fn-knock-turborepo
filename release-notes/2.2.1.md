# fn-knock 2.2.1

- 新增 Cloudflare Tunnel 托管模式，可自动创建和维护 Tunnel、Ingress 规则及 DNS 记录
- 新增 Cloudflare 优选，可组合官方网段与自定义候选来源进行延迟、丢包和下载测速
- 新增请求分析，可按时间范围查看请求趋势、独立客户端、错误率、响应耗时、流量，以及请求目标、访问来源、地域、客户端、响应和安全维度明细
- PoW 验证码新增自适应难度，可自动学习已认证访问的常用地区，为不常用地区设置更高挑战难度
- 加固备份导入与恢复流程，补充备份校验、事务收尾、运行态同步和失败回滚，提升飞牛环境下配置恢复的可靠性
- 改进通行密钥在不同浏览器、平台和 Redis 存储模式下的注册与登录兼容性，并提供更明确的错误提示
- 优化 Cloudflared 与 FRP 连接状态判断，减少短暂网络波动造成的误报警和状态抖动，并增强 DNS 冲突恢复能力
- 修复 Cloudflare 托管模式下公网 URL 规范化和边缘入口处理问题，避免源站端口或错误地址进入回调与访问链接
- 修复子域映射白色图标不可见、公共认证端口提示不明显、加载按钮残影及页面切换后浮动操作栏状态残留等界面问题
- 完善 Cloudflare 管理页面多语言文案，以及 macOS 双架构构建、校验和正式发布流程
