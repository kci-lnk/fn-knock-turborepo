# fn-knock 2.1.0

- DDNS，IPv6波动时稳定性提升避免提示反复切换地址
- 系统设置->飞牛，新增FN Connect流量接入WAF功能，开启后可保护FNC流量免受威胁
- 系统设置->网关->传送门，修复全局传送门开关无效的问题
- 子域映射，新增分组视图，可切换至分组视图，对分组的修改将同步至传送门以及内置的/__select__ 选择页
- FRP、Cloudflared隧道稳定性提升，加入守护机制在进程死亡时及时拉起避免业务中断
- 系统设置->网关，新增“上游异常时显示错误信息”选项，默认选中“显示更少”，在上游业务不可达时不显示上游地址及端口
- Go网关，优化权限控制部分
