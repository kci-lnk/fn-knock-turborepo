# fn-knock 2.5.11

- 支持在飞牛应用设置中配置 Cloudflare Tunnel 专用回源端口，并完善端口冲突诊断，方便同机部署多个实例。Docker 部署也可通过环境变量配置独立回源端口。
- 协议映射支持单条及批量启用、停用，方便集中管理转发规则。
- 企业微信通知支持按需开启 Markdown 格式，并修复并发修改通知配置时可能覆盖其他改动的问题。
- 修复内置 QQ 登录的客户端凭据校验，确保使用内置公共客户端配置。
- 修复 FPK 无法自动升级的问题。

升级提示：修改 Cloudflare 专用回源端口后，请同步更新手工隧道的 Service URL；托管隧道需重新预览并应用配置。
