# 请求日志容量限制：审计与修复

审计范围为 Go 网关分片存储、缓冲写入、清理和查询并发，以及管理端配置与错误展示。

| 问题 | 修复 |
| --- | --- |
| 磁盘写满后 `bufio.Writer` 错误持续保留，释放空间后仍无法记录日志；部分写入可能损坏下一条记录 | 使用可重试的整条记录缓冲，保留已写偏移，只重试尚未落盘的字节。失败期间拒绝新记录并计数，成功后清除异常状态 |
| 重启后继续追加到异常退出遗留的 JSON 尾部，导致后续完整请求也无法解析 | 每次重新打开写入器创建新分片，保留旧文件供查询 |
| 整理先替换内容再更名，中断后旧游标可能指向另一条记录 | 先保留完整原内容并更换文件身份，再原子替换内容；替换失败时原内容仍在新路径，可继续重试 |
| 整理目标名称冲突可能覆盖已有文件，且强制 0644 会放宽原日志权限 | 用排他创建预留新身份，拒绝覆盖；保留原文件权限 |
| 配置保存持有入队锁执行磁盘操作，可能让请求线程等待清理 | 请求日志入队使用非阻塞锁，配置繁忙期间丢弃并计数，继续转发请求；提示文案覆盖此原因 |
| 查询等待写入锁时不响应取消；页码模式错误地解析游标 | 写入锁等待支持取消和超时；仅游标分页模式处理游标 |
| 无新请求跨日后，“今日占用”仍显示昨日值 | 占用快照记录日期，读取时避免将昨日值显示为今日值 |

新增 9 个故障注入与行为回归测试，包含 ENOSPC、部分写入恢复、重命名中断、权限保持、文件名冲突、重启断尾、配置繁忙、查询超时、页码兼容和跨日状态。

验证命令：

- Go：`go test -race ./pkg/gatewaylog ./pkg/admin ./pkg/proxy ./pkg/config`
- 前端：请求日志设置及分页请求组件测试
- 合约：共享 gRPC 版本和网关提交引用一致性检查

本次未改变默认容量、日志保留策略或 HTTP/gRPC 字段。旧版超限单文件仍按照已说明的策略保留最新一个分片，以限制整理临时空间。
