# fn-knock 2.2.1

> [!WARNING]
> **这是 Beta 测试版本，不建议直接用于关键生产环境。** 请先备份现有配置和数据；如遇问题，请携带诊断信息反馈。此版本不会推送到稳定版自动更新渠道。

## 主要更新

- 新增请求分析页面，可按今天、近 7 天、近 30 天或自定义日期查看请求趋势、独立客户端、错误率、响应耗时、流量，以及请求目标、访问来源、地域、客户端、响应与安全维度的明细。
- PoW 验证码新增自适应难度，可自动学习已认证访问的常用地区，并为不常用地区设置更高挑战难度；同时补充新的难度预设并优化设置界面。
- 增强 Cloudflare 访问速度优选，新增逐域名状态与冲突处理，完善托管资源所有权对账、DNS 冲突恢复、错误提示和健康检查回退。

## 修复与改进

- 加固备份导入与恢复流程，补充备份校验、事务收尾、运行态同步及失败回滚，提升飞牛环境下恢复配置的可靠性。
- 改进通行密钥在不同浏览器、平台和 Redis 存储模式下的注册与登录兼容性，并提供更明确的错误提示。
- 抑制 Cloudflared 与 FRP 的瞬时断连事件，减少短暂网络波动造成的误报警和状态抖动。
- 完善 Cloudflare 管理页面的多语言文案，并修复加载按钮残影等界面问题。
- 修复子域映射中白色图标不可见，以及公共认证端口提示不够醒目的问题。
- 优化浮动操作栏的生命周期管理，避免页面切换后的状态残留。
- 调整 macOS 构建流程，仅在正式发版 Tag 时构建发行产物。

## Beta 说明

- Cloudflare 自动托管、访问速度优选和请求分析仍属于重点测试功能，不同 Cloudflare 套餐、区域、证书状态与日志规模下的表现可能不同。
- 测试版只发布固定版本产物，不更新 Docker `latest`、官网/CDN 稳定版下载地址或应用内自动更新清单。
