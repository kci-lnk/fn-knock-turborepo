# fn-knock 2.4.10

- 新增 Rust 运行诊断，位于事件中心，状态，支持按需采集 CPU、内存、后台任务与数据库操作统计，并导出诊断报告，方便排查运行异常。
- 增强 Webhook 自定义通知，支持通过固定字段名引用通知详情，并在编辑器中按事件选择变量，方便对接第三方服务。
- 优化 WAF 事件采集，采用可取消的长轮询，减少空闲轮询和重复加载配置的开销，并在配置变更后及时唤醒采集任务，可显著降低CPU占用率。
- 修复 Cloudflare 隧道在部分连接异常时误报整体故障的问题；修正 fnOS Lite 托管隧道的网关端口。
- 修复 WebSocket 长连接被固定时限中断的问题，完善取消处理；及时淘汰无响应的 HTTP/2 上游连接，提升代理连接稳定性。
- 加强 Go 网关代理缓冲区的容量限制与内存诊断，改善资源管理。
- 优化移动端标签页导航、应用栏触摸拖动与终端目标选择体验。
- 页面资源加载失败时提供手动重试和刷新入口，方便恢复访问。
