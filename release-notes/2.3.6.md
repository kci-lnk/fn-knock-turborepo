# fn-knock 2.3.6

> [!IMPORTANT]
> 本次为重要稳定性更新，重点修复 fnOS 分享访问和认证链路在高并发、服务异常及 Docker 会话迁移场景下的可靠性问题，建议所有用户尽快升级。

- fnOS 分享链接支持访问码校验后的免登录访问，并加强回退识别，避免合法分享请求被错误拦截
- 优化认证桥接的排队、并发伸缩和响应超时处理；认证服务不可用时，网关将明确返回 HTTP 503
- 修复 Docker 会话 IP 迁移时的并发冲突，并确保 Docker 构建全过程绑定同一 Go 网关源码提交
- 修复请求分析中的 IP 国家或地区代码丢失问题
- 修复 Synology 磁盘休眠可能导致服务启动异常的问题
- 加强工具栏图标的 Base64 内容及解码后尺寸校验
- 修复可见性规则在服务启动时重复重放的问题
