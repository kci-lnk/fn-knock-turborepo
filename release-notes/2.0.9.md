# fn-knock 2.0.9

- 修复“高级认证配置”相关问题，改善放行飞牛 App 时的兼容性，并优化配置流程与使用体验。
- 修复 DDNS 优选地址手动指定后仍被系统推荐结果覆盖的问题，明确采用“手动指定 > 系统推荐”的优先级。
- 子域管理新增自定义应用图标上传功能，可为指定应用手动设置图标。
- 完善官网、文档与 GitHub Actions 自动化更新流水线，并在相关界面显著展示当前版本号和更新日志。
- 提升日文、韩文界面适配质量，并新增 Windows 管理面板支持。
- 修复权限自定义中无法指定协议映射的问题。
- 侧边栏菜单新增自定义排序，可在“系统设置 → 功能 → 侧边栏菜单排序”中调整。
