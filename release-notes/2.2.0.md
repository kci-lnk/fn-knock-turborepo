# fn-knock 2.2.0

> [!WARNING]
> **这是 Beta 测试版本，不建议直接用于关键生产环境。** 请先备份现有配置和数据；如遇问题，请携带诊断信息反馈。此版本不会推送到稳定版自动更新渠道。

## 主要更新

- 新增 Cloudflare Tunnel 托管模式：使用最小权限 API Token 自动创建并维护专用或已有 Tunnel、Ingress 规则与 DNS 记录，支持变更预检、远端漂移检测和安全清理。
- 新增 Cloudflare 访问速度优选：可组合官方网段与自定义候选来源进行延迟、丢包和下载测速，为业务域名选择更合适的入口；健康检查失败时自动回退到标准 Tunnel。
- 优化 Cloudflare Tunnel 配置体验，简化连接、预检、应用和故障排查流程，并补充候选来源、实际 PoP、探测位置和切换记录等信息。
- 新增 macOS 13+ 原生 CLI 发行版，同时支持 Intel 与 Apple Silicon，使用 `launchd` 和 `knock` 命令管理服务。

## 修复与改进

- 修复 Cloudflare 托管模式下公网 URL 规范化问题，避免源站端口或不正确地址进入回调与访问链接。
- 加固 Cloudflare 边缘入口处理，提升代理请求和公共 URL 推导的安全性与一致性。
- 完善 macOS 双架构构建、校验、发布与补发流程。
- 更新锁定依赖，修复 `brace-expansion` 依赖版本问题。

## Beta 说明

- Cloudflare 自动托管和访问速度优选属于本轮重点测试功能，不同 Cloudflare 套餐、区域与证书状态下的能力可能不同。
- 测试版只发布固定版本产物，不更新 Docker `latest`、官网/CDN 稳定版下载地址或应用内自动更新清单。
