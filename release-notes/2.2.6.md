# fn-knock 2.2.6

- 新增优选边缘 IP 与代理目标路径模式，提供更灵活的 Cloudflared 和上游路径配置能力。
- 新增 Go 网关内存管理，并优化运行时内存占用与前端加载性能。
- 提升 Cloudflared 配置协调与应用流程的容错能力，加固目标路径模式的配置约束。
- 修复切换运行模式时可能发生的死锁问题。
- 修复 ACME 证书任务卡住后无法恢复或停止的问题。
- 加固群晖（Synology）冷启动时的网关启动流程。
- 移除同源请求强制校验，修复部分部署方式下的请求受限问题。
- HTTP 响应优先使用 Brotli 压缩，并拆分过大的管理端前端模块。
- 修复发布说明中 GitHub 风格提示块的渲染问题。
