# fn-knock 2.5.1

- 网关请求日志支持按客户端 IP 分组查看，并可展开查看对应的请求明细。
- 仪表盘在线设备按 IP 聚合展示设备类型图标，方便识别当前访问设备。
- ACME 证书支持保存到自定义目录，便于其他服务直接使用申请和续期后的证书。
- 防火墙额外放行端口支持配置端口范围，并完善输入校验与错误提示。
- Web 终端支持在连接编辑窗口中配置进程保留方式，可选择关闭页面后继续运行，或在最后一个页面离开后结束会话。
- 修复临时高级认证授权仍可能被扫描器检查误拦截的问题，并完善临时授权缓存隔离。
- 修复认证缓存失效与并发请求之间的竞态，避免旧认证结果重新写入缓存。
- 修复 FRP 使用自定义公网 HTTPS 端口时，认证流程中的端口处理不一致问题。
- 修复飞牛证书同步校验未使用实际配置的 HTTPS 端口的问题，并增强证书异常恢复处理。
- 修复 Web 终端日志复制在部分浏览器中不可靠的问题。
- 完善代理转发的 Cookie 兼容性处理，并过滤响应尾部字段中的内部跟踪信息。
- 优化预期停机与重启事件的处理，减少误报，并完善 FPK Lite 停机保护。
- 优化认证流程中的批量查询、请求数据复用与缓存读取，减少重复解析和内存分配。
- 优化 SQLite 批量读取及认证预检读取路径，减少对写入连接的占用。
- 优化配置指纹缓存、空闲状态检查与诊断轮询，减少运行时重复工作。
- 限制认证防重放记录的内存占用，完善网关认证等待超时与上游故障诊断。
