# fn-knock 2.4.0

- 重构，更好的Web终端，全平台支持，支持配置多SSH目标。（FPK用户请升级后手动配置SSH连接信息）
- 新增子域名路径级认证控制，支持将特定路径设为公开访问模式
- 为管理端、认证链路和 Go 网关加入统一 Trace ID，便于跨组件追踪请求和排查异常
- 传送门优化：预热子域名资源、修复缓存带来的问题，解决在群晖DSM无法注入传送门的问题
- 优化登陆认证页在Cloudflare Turnstile状态下快捷登录不可见的问题，并优化登录页资源加载逻辑
- 修复在HarmonyOS下点击两次才有反应的问题 & 修复在飞牛App下无法打开fn-knock管理界面的问题
- OpenWrt 不再自动修改主机防火墙规则，避免覆盖用户已有的网络与安全配置
- 子域映射，添加“目标地址优化”功能，位于“一键发现”按钮旁边的下拉菜单，可批量将127.0.0.1的目标和局域网地址互换
- 子域映射，手动添加映射时，IP输入框提供更多局域网IP地址候选项
- 其他UX体验优化
