# fn-knock 2.4.2

- 新增静态资源映射，在子域映射->新增映射，选为目录方式，支持为子域映射配置本地目录索引、静态web业务
- WAF 新增可配置的拦截响应，可选择返回普通错误页或伪装为连接失败
- 优化管理端页面滚动区域、侧边栏与弹窗焦点恢复，改善移动端 DDNS 操作体验和无障碍访问
- 优化移动端 SSH 安全配置布局，并修正仪表盘流量颜色显示
- 为静态请求路由类型补充多语言显示名称
- fnOS 网络调优会先检测 BBR 内核模块，避免在模块可用时错误隐藏相关设置
- Web 终端新增本机 PTY：完整 FPK、Linux、macOS、OpenWrt 可在确认服务身份与 root 风险后显式启用，默认关闭；SSH 目标及现有 HTTP 长轮询行为保持不变。FPK 终端链路严格使用 `index.cgi` 转发到环回 Rust 服务，不接入飞牛统一网关、Go/gRPC 或 WebSocket。
