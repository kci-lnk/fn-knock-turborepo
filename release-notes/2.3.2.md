# fn-knock 2.3.2

## 新增功能

- 新增第三方导航面板同步功能，位于子域映射->一键发现旁边（下拉菜单）->同步到导航面板
- 新增扫描器拦截路径白名单管理，位于系统设置->拦截->路径白名单，遇到此类误封时，可在会话管理->扫描器黑名单中解除封锁并加白名单
- 协议映射，新增流量活跃 IP 查询功能及相关 API 接口，可在该页面点击“流量”字样查看。
- 为网关日志分析请求增加超时控制。
- 为 Cloudflare 入站流量预留独立端口。
- 改进 SQLite 分析数据隔离和认证并发控制。
- 优化自定义主机名管理和 DNS 激活逻辑。
- 改进 Cloudflare 认证失败时的错误处理和用户提示。
- 优化 Cloudflared 反向代理子域名模式下的对外端口解析。
- 改进软件包构建及验证测试中的可复现文件修改时间处理。
- 修复 群晖DSM 网关启动同步遇到临时错误时的重试问题。
